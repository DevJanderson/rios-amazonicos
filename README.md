# Rios Amazônicos

Monitor aberto das cotas dos rios **Negro, Solimões, Madeira e Amazonas**.
Reúne dados oficiais (ANA, SGB, Porto de Manaus), limpa e guarda o histórico, e
entrega painel e alertas no Telegram para a comunidade amazonense.

> 🚧 Em construção. Acompanhe o andamento em [docs/fases.md](docs/fases.md).

- Requisitos e visão do produto: [docs/PRD.md](docs/PRD.md)
- Stack: Python (uv), PostgreSQL, marimo, n8n, Telegram
